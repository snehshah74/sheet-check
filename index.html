        How it works

        Rules you can check, not a model you have to trust.

        No AI model runs here

        It reads the text and positions already inside the PDF, finds the labelled title-block fields (sheet no., title, revision), and applies plain rules. The same file always gives the same answer, so every flag can be traced to the exact text it came from. That is the boxes you see on each sheet.

        Every field carries a confidence

        Read from a labelled field: confident. Found by pattern or by size: marked as a guess. Missing: marked as not found. Only fully labelled sheets count as read. Everything else goes to a person.

        Where a model would earn its place

        Scanned sheets and unfamiliar title-block styles. A vision model could read those, but it should propose and a person should confirm, because a confident wrong sheet number is worse than a blank one.

        What it checks

        1. Duplicate sheet numbers across the set
        2. Skipped numbers inside a series (A-101, A-103 → is A-102 missing?)
        3. Blank or missing revision on a sheet
        4. Sheet index vs. the sheets: listed but absent, present but unlisted, revision or title mismatch
        5. Pages with no readable text (scans), listed instead of guessed

        Before you trust it

        • The sample is synthetic. Real drawings are messier, and your title blocks may use labels it has not seen. On a style it had never seen, the first version auto-approved nothing and sent every sheet to review.
        • It needs a PDF with a text layer. Scanned pages are listed as unreadable, not read.
        • “Skipped number” can be intentional. It flags things to look at; it does not decide.
        • After you correct a sheet, the problem list is not recalculated. Reload to re-run.
